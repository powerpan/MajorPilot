## 资料与版本

背景问题不再是账号激活或开始专业体验的门槛。省略字段表示未填写，显式 `null` 表示主动跳过，问卷声明的 `UNSURE` 表示不确定；不把三者转成默认选项或能力评价。已填写内容应保留，单题跳过不能丢弃其他题目的回答。

正式资料是不可覆盖的 Decision Profile。编辑使用独立草稿，带草稿 revision 和所基于的正式资料版本；取消编辑或保存失败不改变正式资料。提交在同一事务内追加版本并校验冲突，重复请求复用结果。多标签页旧草稿不得自动覆盖新资料。

空白重填必须由用户主动选择，不因进入页面而清空正式资料。已有任务、历史报告及其背景、内容和证据引用不变；后台读取报告时不得回读最新个人资料。草稿也属于账户个人数据，纳入既有导出、删除和身份隔离边界。

## 推荐与自主开始

首次推荐仍使用既有确定性排序规则。`scenario_preference`、`considered_majors`、`work_elements`、`major_familiarity` 四项有效且完整时才生成个性化初始推荐；不补齐缺失值。资料完整情况与能否推荐是两件事：背景未全填但排序输入足够时可推荐，排序输入不足则不显示个性化推荐，也不回退显示上一资料版本的初始推荐。

无初始推荐时，学生仍可查看三个专业并直接选择已开放方向。推荐驱动的选择继续使用 `decisionId`，自主选择使用 `majorCode`；后台校验开放状态、身份、归属、幂等与同专业复用。自主选择不制造推荐记录或假推荐理由。没有背景资料时仅保留明确为空的背景快照，不写入虚构回答。

新创建的任务使用创建时最新的正式背景；已有 NEXT 推荐仍可作为选择依据，推荐本身保留原来的背景和报告证据引用。已创建任务不得被后续资料提交追溯修改。同一时刻仍只允许一个活动体验；跨专业切换先确认暂停，继续时使用原进度和版本。报告必需的步骤与反思不允许跳过后伪造完成。

只有草稿、还没有正式资料时，自主开始会为体验保存明确为空的内部背景快照。这不算用户提交资料，资料页仍显示未提交，原草稿仍可继续提交；也不产生虚构的问卷提交事件。

## 接口复用与补充

沿用现有会话、CSRF、资源归属、错误协议、幂等键及任务接口。学生资源路径前缀为 `/api/app/v1`。

| 接口 | 本轮作用 |
| --- | --- |
| `GET /profile` | 返回本人最新正式资料和独立草稿；展示答案及缺失状态，不返回能力分数 |
| `PUT /profile/draft` | 带 `expectedRevision` 和 `baseProfileVersion` 保存草稿，不提交正式资料 |
| `POST /profile/submit` | 校验版本并追加正式资料；排序输入足够时附推荐，否则推荐为空；要求幂等键 |
| `POST /profile/draft/discard` | 校验草稿版本后取消编辑，不影响正式版本 |
| `POST /api/public/v1/intake-sessions/{id}/finish` | 允许空或部分资料完成本次匿名填写，保留认领凭证及注册安全规则 |
| `POST /experience-runs` | 兼容既有 `decisionId`；新增 `majorCode` 自主开始，不依赖初始推荐存在 |
| 既有 dashboard、报告、比较与额度读取 | 保留真实数据；不把浏览介绍当完成任务 |

具体 DTO、错误码与可执行契约见 [资料与草稿合同](../contracts/openapi-profile-flow.json)，匿名 finish 在 [P1 合同](../contracts/openapi-p1.json)，自主开始同步至 P2–P6 及方法体验合同。数据库只新增 [V14](../database/migration/V14__profile_draft_and_partial_answers.sql)，不改写已执行迁移。草稿位于账户自身的 JSON 列及单调 revision 列，继承账户删除与个人导出边界。支付演示没有支付、订单或额度写接口，也不采集付款资料。

## 页面边界

卡片中保留简短中英文名称、说明、状态和一个主要行动；不嵌入整份报告。未开放项可阅读介绍，已结束项进入对应运行的报告或报告状态。手机可阅读资料、介绍和报告；技术操作仍要求宽屏，不扩展移动工作区。

支付页在所有状态明确说明：不会扣款、不会创建真实订单、不会增加或消耗报告额度。费用区域均为“待定”；结束只显示“演示结束，未产生订单或费用”。刷新或重新打开只是重置页面演示，不产生业务副作用。

## 人工复核入口

启动已构建的新版本后，从真实账号的 `/app` 检查以下路径。普通账号需完成注册／邮箱验证，邀请账号需本人确认条款与隐私；测试账号与口令不写入文档。这份清单供后续验收使用，不代表已经完成真人验收。

| 路径 | 应看到的结果 |
| --- | --- |
| 主页 → 查看完整资料 → 修改 → 保存草稿 → 刷新／取消 | 正式资料不变；草稿可恢复；取消后仍保留原正式版本 |
| 完整资料 → 从空白重新填写 → 提交 | 不预选答案；追加新版本；旧任务、冻结输入与报告不改写 |
| 首次问卷 → 单题或整份跳过 → 主页 | 已填内容保留，账号前置条件仍有效；偏好不足时没有初始推荐，仍可自行开始开放专业 |
| 三专业卡片 → 开始／继续／报告 | 操作与对应 Run 状态一致；切换需确认暂停，手机保留阅读入口与宽屏任务限制 |
| 主页 → 方案与支付（演示）→ 查看 → 确认 → 结束 | 显示“演示结束，未产生订单或费用”；刷新或退出不改变额度、资料及任务 |

本轮后端尚未在主开发库启动。启动新版前应保留需要的私有备份，并知道正常 Flyway 启动会应用 V14；不用手工修改旧迁移，也不直接覆盖运行中的 JAR。项目启动、停止和构建入口见[根 README](../README.md)。
