## 1. 核心创意

MajorPilot 是帮助申请者实际探索专业工作方式的产品，不是通用问卷、性格测试或适配度打分器。首页首先呈现「同一个问题，三种专业视角」：AI 观察模型错误、DS 从数据中找证据、BA 把分析转化为可验证的行动。

采用浅纸色、墨黑、群青与少量橙色；大字编辑式排版、选择性宋体强调、透明观察镜片构成稳定记忆点。页面通过开放排版、细线和纸质任务标本组织信息，不复用绿色圆角卡片模板。

营销页可以表达愿景，但当前能力必须真实：P1 可完成信息收集、初始建议、注册和保存选择。LumenLearn 为虚构学习平台，任务展示明确标为「任务预览」「专业任务即将开放」，不制造已开放的任务入口、成功率、用户数或院校背书。

## 3. 设计系统

- 色彩锁定：浅暖纸色 `#F7F5EE`，墨黑 `#171A1D`，群青 `#304FFE`，橙色 `#F45B35`；白色仅用于必要控件／高对比文字。禁止重新变成绿色主题或深色云雾渐变。
- 字体：中文无衬线承担导航、问题、控件和大部分内容；宋体仅用于标题中的特定强调、专业缩写和编辑式数字。优先本地字体栈，不为页面接入第三方字体追踪请求。
- 字级：首页大标题建立鲜明层级；问卷题干和推荐标题略降一级；正文和选项保持易读，不将辅助文案缩成装饰性小字。
- 组件：黑色主操作、蓝色细侧边与圆形箭头尾端；文字型次要操作；细线分隔的选择行；单个任务纸张容器；无嵌套卡片。
- 表单：原生有标签的输入与单选／多选，明确选中标记和焦点轮廓，不能仅靠颜色表意。禁用态与保存状态由实际请求结果控制。
- 图标：蓝／橙双折面的飞行标记、单线右箭头／回退箭头、单选圈。优先原生可伸缩几何，不引入不一致的通用图标库。
- 版面：桌面首页左右张力；下半页专业侧栏＋单任务标本；问卷左侧大编号＋集中内容列；推荐主理由区＋其他专业比较栏。手机自然变为单列，保留首要操作，不横向溢出。
- 动效：只用于交互反馈、渐进呈现与专业预览切换；尊重 `prefers-reduced-motion`，不强制滚动、不妨碍填写、不让动画承担必要内容。

## 4. 首屏可见文案清单

以下是允许的固定页面文案；不要自行插入促销数字、无来源承诺或额外产品模块。

- 导航：`MajorPilot`、`如何体验`、`探索专业`、`登录`。
- 主标题：`别只看专业介绍。` / `先试试，你会做什么。`
- 介绍：`从 AI、Data Science 与 Business Analytics 开始，在真实任务的简化情境中，感受不同专业的工作方式。`
- 主操作：`找到我的第一站`；次要操作：`先看看专业任务`。
- 当前能力：`当前可获取初始建议；专业任务即将开放。`
- 专业标注：`AI / 检查模型错误`、`DS / 从数据中找证据`、`BA / 把分析变成行动`。
- 主视觉题注：`同一个问题，三种专业视角`。
- 辅助短句：`更清晰的选择，从一次真实的尝试开始。`
- 过渡：`03` / `不是测出你是谁，而是看见你愿意怎么做。` / `不同的专业，通向不同的思考方式，也通向不同的可能`。

概念图中极小的英文装饰字仅为视觉辅助，不能替代产品说明或成为新功能承诺；手机可以隐藏此类非必要重复文字。

## 5. 页面及状态清单

首页依次为主视觉、观点过渡、三专业可切换任务预览、三步流程、收尾操作和页脚。AI／DS／BA 切换展示的是 09 号文档中的任务方向，不是可执行任务或隐藏标准答案。如何体验、三个专业说明、隐私和条款使用同一排版系统。

问卷的第 4 页视觉代表其他 11 页；不同题型复用选择行、矩阵和原生字段。场景排序明确允许并列，不用不可访问的拖拽作为唯一方式。保存中、保存失败、离线、冲突、恢复和过期状态必须可辨认，不能为了画面整洁隐藏错误。

推荐页的 DS 只用于视觉示例。实际第一名、备选、2–4 条理由及支持说明由 API 驱动；不复制图片中的 DS 文案给每个用户。历史建议、注册前／注册后和接受／改选的必要控件按 12、14、15 号文档延展，不能假报已经开始体验。

邮箱／账号页沿用字体、操作和细线体系，保持低干扰。令牌链接立即清除 fragment，错误和恢复指引不泄漏凭据。P0 技术页留在 `/p0`，与正式产品页面分开。

## 6. 验收要求

实现后必须在 1536 × 1024 原生参考尺寸，以及约 390 像素手机宽度查看实际截图。逐项比对：首屏构图／密度、色彩、字体层级、雕塑尺度及无染色处理、按钮与选择行、下半页节奏、问卷及推荐状态。确认首屏文案没有凭空新增内容。

Chrome 与 Edge 真实流程测试、类型检查、构建和截图检查分别记录；截图相似不能替代真实操作，业务测试通过也不能替代视觉确认。任何必要差异需标明，例如服务端实际推荐不等于设计图中的 DS、手机换行和动态错误提示。

## 8. 实际页面对比结果

认可概念与最终浏览器截图已由主代理分别使用 `view_image` 检查，1536×1024 原生尺寸无尺寸阻断；390 手机和 1200／1265／1440 宽度另查，未见横向溢出。Codex 内置浏览器也实际打开首页并完成 AI→DS→BA 预览切换；它最初出现一次授权审核超时，按工具允许重试成功，并非实际不支持本地页面。

| 比较点 | 核验及修正 |
| --- | --- |
| 构图和色彩 | 首页左右比例、浅纸色／墨黑／群青、03 过渡和开放式布局匹配；无绿色模板回退 |
| 主视觉 | 独立镜片资产、三专业原生标注和自然阴影；没有整页截图当网站或附加染色 |
| 字体与操作 | 黑体／宋体层级、橙色数字、黑蓝箭头组件一致；缩小桌面宽度时已修正正文碰撞 |
| 下半页 | 真正可切换的任务预览、纸纹和影像带、三步流程、收尾操作；移除低对比初稿 |
| 问卷 | 左侧大编号、顶部进度、开放选择行和可见焦点；取消灰色 hover 色块，长正式题干平衡换行 |
| 推荐 | 完整专业缩写轮廓、真实理由、右侧比较和竖线；修复曾被遮挡的大字，保留服务端实际专业而非伪造 DS 示例 |
| 手机 | 单列、首要操作、可键盘展开导航、矩阵和推荐阅读无横向溢出；主视觉继续出现而非被完全移除 |

首屏固定文案比对未发现新增无来源承诺。必要差异仅包括：真实问卷题干与按钮 `保存并继续`、服务端动态专业／理由／支持说明、结构化解释状态、响应式换行及可访问焦点，不以贴图伪造一致。已按这些明确差异忠实核验认可方向，当前未见剩余的实质视觉偏差。
