# P4 DS 工作区视觉合同

> 2026-09-21：设计准备，不代表前端已经实现。沿用 P1/P2/P3 编辑式视觉，用户已授权按文档自主选择。使用前端设计、图像生成、统计可视化技能形成下列实施约束。

## 1. 关键屏与资料

- [D2 数据质量](./design/p4-ds-quality-v2.png)：原始表概览、问题识别、三个策略、两项理由、计算与等价 Python 说明。
- [D4 变量关系](./design/p4-ds-relationship-v2.png)：两种分析模式、变量控件、散点图、有效样本与分母、原始表格回查和学生观察。
- [D5 检查解释](./design/p4-ds-uncertainty-v2.png)：分层控件、整体/分层的区间或统计、局限解释和学生判断。
- [完整生成提示](./design/p4-generation-prompts.json)：内置 image_gen，两轮；第二轮修正偏离既有侧栏序号、字体和底部动作范围的问题。未调用项目供应商 API Key。

D1/D6/Reflection 使用既有原生资料表和结构化表单；D3 使用同一分析结果组件的直方图变体，不新增仪表盘体系。所有文字、表单、数据表和图表用 Vue/HTML/SVG 生成，图片仅是设计参照。

## 2. 设计系统与必要差异

既有 shell 是最高优先的视觉参照：纸色 #F7F5EE、墨黑 #171A1D、蓝 #304FFE、橙 #F45B35；76px 顶栏，左导航橙色大号序号、中心滚动区、右提示栏，底部动作仅固定于中心区域。现有 MajorPilot 品牌图形保持，不采用生成图中的变形标志；导航用细蓝竖线＋蓝文字，不用新增纯色色块。

标题40px上下，正文18px，控件16px以上；表格/轴标签可较小但保持14px以上与足够对比。灰色细线、开放布局，不增加卡片/投影/装饰性指标。1024–1100 延续帮助抽屉；<1024 保留明确设备限制，不强行缩小图表或改变既有任务编辑边界。

概念中散点和区间明确标“结构示例”，仅说明编码。实现绝不拿示意值冒充实际结果：未运行显示可读空态，无假点/假区间；运行后完全使用服务端复核结果与真实样本数。示意标题不进入实际结果区，替换为当前变量和统计口径。真实结果密度、版本信息、限额/复用/失效状态和长文本按合同显示，必要时中心区滚动，不把所有信息挤进首屏。

标题/步骤/按钮沿用图中措辞，具体任务说明与校验长度以最终不可变 manifest 为准。学生输入始终空白；完整原始数据与精确数值采用可展开表格，不让仅凭悬浮提示才能读取关键信息。

## 3. 可视化实施清单

| 视图 | 统计问题与编码 | 精确值、状态与限制 |
| --- | --- | --- |
| D2 质量表 | 哪些行/字段缺失、重复或不适用；前后计数表 | 明确原始/保留/修改数，不以红色直接宣布合理极值为错误 |
| D3 直方图 | 变量如何分布，而不只看平均数；固定数值区间和频数 | 横轴单位、纵轴记录数、零起点、区间边界、n/缺失/不适用、分位摘要 |
| D4 分组完成率 | 哪些群体的完成比例不同；共享0–100%轴的点与 Wilson 区间 | 完成数/实际分母、区间数值和排除数量，不把相关差异写为原因 |
| D4 散点 | 两个数值变量如何共同变化；每条有效记录一个点 | x/y单位、成对n/r、null/常数边界、原始点数据表；不连成趋势线，不移动点伪造均匀分布 |
| D5 分层 | 整体关系是否在群体内仍成立；共享尺度、小组纵向对比 | 分组分母与区间或散点统计，不能给 r 套 Wilson，不做总体因果结论 |

渲染选型为 Vue 管理 SVG DOM，纯 TypeScript 几何/尺度函数；最多360点，不新增大型图库，仅为使用库而引入 D3 不增加能力。计算与绘制分离，状态仍由 workspace 已保存 response/source revision 管理，不另造浏览器分析真相。浅蓝点/线配明确标签，颜色不是唯一语义；无自动动画、无裁掉极端值、无双轴。

SVG 有 title/description，核心数字在原生表格重复呈现；keyboard 可展开/收起、表单有 label/focus，reduced-motion 无损。单点/全缺失/常数时给解释，不渲染 NaN 位置或误导性零值。直方图计数必须与表格/有效 n 一致。
