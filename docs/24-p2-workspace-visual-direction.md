# P2 通用工作区视觉规范

> 2026-09-21，延续用户已确认的 P1 编辑式视觉。新增页面按用户授权自主推进，不等待离线期间的逐项确认。

## 1. 参考和范围

主工作区参考：`design/p2-workspace-v1.png`（内置 ImageGen，1536×1024）。这是技术演示的第三步状态，不是 AI/DS/BA 已发布证明。所有字、表格、数字和操作由 Vue 原生渲染，禁止整页贴图；复用现有 MajorPilot 标志，而不是改成生成图中略有差异的纸飞机。

独立反思参考：`design/p2-reflection-v1.png`（1536×1024）。左侧橙色序号、右侧集中表单、三个固定必填问题和可折叠选填区域；保留暂停、返回任务回顾、提交并完成演示。兴趣环节按真实 Task Version 完整列出，不受图中三个示例选项限制；必填项默认不替学生选择。生成图中的品牌符号和按钮箭头仍复用既有正式组件。

体验介绍复用既有开放排版、集中主标题和动作组件，显示真实任务标题、6–10 分钟技术演示时长、所需设备、保存说明和返回入口。手机只读进度及设备限制，不给出看似可用的开始/编辑操作。暂停切换确认、离线和 revision 冲突使用同一字体、细线与明确动作，错误不靠颜色单独表达。

## 2. 设计系统与组件

- 背景保持 `#F7F5EE` 浅暖纸色；文本 `#171A1D`；主强调 `#304FFE`；序号少量 `#F45B35`。不使用绿色模板或装饰渐变。
- 顶栏只有品牌、当前任务、真实保存状态、暂停退出；桌面下方依次为步骤栏、主工作区、帮助栏，细线分隔，不嵌套卡片。
- 左栏：大宋体序号、清楚的步骤标题、原生完成标记和当前蓝色竖线；不可访问步骤不能假装可点。
- 主区：约 40px 桌面标题、18px 正文，表格和控件不少于 14px；宽屏留白，1366px仍优先保证主区可读。
- 表格：真实表头与网格，浅中性表头；结果是开敞的三列数字条，不作专业分数。
- 控件：原生 radio/select，蓝色描边辅助按钮；黑色主按钮搭配细蓝边和圆形箭头，复用 P1 组件。
- 帮助：三级清晰分行，主动逐层请求；不是聊天框。不宣称静态提示为模型生成，不以求助扣分。
- 1024–1199px 帮助变为抽屉；更窄设备显示任务编辑限制。保存/只读/当前步骤始终可辨。

## 3. 主屏固定文案和动态信息

标题“工作区上手：读取与调整”；步骤“准备工作区”“读取合成样本”“调整参数并预览”“记录观察”“提交任务”，之后为“体验反思”。当前步骤说明“只改一个参数，观察结果如何变化。”操作“暂停并返回”“运行预览”“完成此步骤”“上一步”“查看计算说明”。帮助“需要一点提示？”“先自己尝试。你可以按需逐层查看提示。”“概念方向”“操作思路”“一个具体线索”。边界“演示不生成专业报告”。

样本数值 2/5/8/11；倍数2、全部样本时结果为样本数4、总和52、平均值13。这些只是指定输入对应的参考状态；运行前不展示假成功结果，实际参数/数据/步骤/保存时刻均来自当前内容和服务端状态。必要的错误、静态回退标签、执行版本与结果过期说明优先于效果图省略的状态。

## 4. 验证约定

实现完成后对照参考和浏览器实际截图，至少核查布局、字级、配色、控件、表格/结果、帮助层级和窄屏行为；记录1536×1024、1366宽、1024–1199和手机尺寸。文案变化只能来自当前业务内容、动态状态或明确的可访问性要求。实际交互应覆盖保存→运行→提示→完成步骤，以及暂停/恢复/冲突/只读；图片相似不代替功能验收。
