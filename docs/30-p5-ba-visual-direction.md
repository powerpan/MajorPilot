# P5 BA 工作区视觉合同

> 2026-09-21：依据[已审定的 P5 工程设计](./29-p5-engineering-plan.md)实施。Chrome/Edge完整业务流程已通过，主代理已同轮对照下列三张概念与实际截图；B4宽表裁切修复后的完整流程、内部边界和键盘补验也已通过，范围见第4节。沿用现有 MajorPilot 编辑式工作区，不启动新的设计体系。专业人工审核与真实目标用户计时仍是独立门禁，用户未逐图批准。

## 1. 关键屏与复用范围

- [B2 定义指标](./design/p5-ba-metric-v1.png)：标题“先把指标说清楚”，分子/分母、两期批次范围、计算按钮、两期计数与比例、指标理由。图中表格是合成数据布局示例，不是学生本次运行结果。
- [B3 定位漏斗](./design/p5-ba-funnel-v1.png)：标题“下降发生在哪一环？”，继承窗口摘要、两期同刻度阶段条形图、人数、重点环节选择与判断依据。累计与相邻转化分别解释，不把人数损失自动认作原因。
- [B6 设计行动，最终 v2](./design/p5-ba-action-v2.png)：标题“先做什么，如何验证？”，真实上游群体摘要、行动描述与依据、成功目标、支持联系护栏、复盘时间及小范围验证计划。使用 v2，不采用早期版本编造的人群背景。

B1 复用原生情境资料、数据字典和业务边界表单；B4 复用指标结果表、两期对照条形图与单一细分维度控件；B5 用原生结构化表单分别呈现“观测／可能原因／尚缺信息”；Reflection 复用既有独立反思流程，不并入 B6 或假设方案提交即完成反思。

全部文字、导航、控件、表格、状态和图表均由 Vue/HTML/SVG 原生生成。概念图只用于视觉对照，不能作为页面背景或可点击图片 UI，不引入任意 SQL/Python 编辑器、大型 BI 图表搭建库或额外仪表盘。

## 2. 设计系统与概念到实现的必要修正

现有工作区 shell 优先：纸色 `#F7F5EE`、墨黑 `#171A1D`、蓝 `#304FFE`、橙 `#F45B35`；76px 顶栏、左侧橙色大号步骤序号、蓝色细竖线与选中导航、中心内容滚动区、右侧提示栏。底部上一步与主 CTA 只固定在中心区域，不覆盖侧栏或输入内容。保持既有 MajorPilot 品牌图形和图标，不重画概念中的品牌替代物。

标题约40px，正文18px，控件至少16px，表格及图轴标签至少14px；采用细灰分隔线、开放布局与充足留白，不新增卡片网格、投影、装饰性指标或密集徽章。成功/错误/选中状态同时使用文字或形状，不依赖颜色。完整表格可在自身容器内滚动，不能使整个页面横向溢出。

必须在实现中修正、不能照抄概念图的内容：

1. B3 图题“各环节累计完成率对比”改为“各环节累计到达率对比”。只有完成课程这一阶段才是完成率；累计到达率以报名人数为分母，相邻转化率以对应上一环节人数为分母。
2. 所有“首周活跃”显示为“开课首周活跃”，解释为首次开课后7天内达到活跃条件，且仍处于报名后28天观察期；不是报名首七天活跃。数据是合成事件标记，不声称存在或审计过真实时间戳。
3. B2/B3 概念左下角的 `AI · 工程预览` 改为 BA；版本、专业、任务标题与状态取当前固定内容及 Run，不把示例版本号或完成勾选硬编码。顶栏“已保存”仅在真实保存成功时显示。
4. 右侧帮助标题、三级提示正文、展开状态与按钮行为以最终不可变 manifest 和既有提示合同为准，不把图中的提问标题误当新增问题或 AI 已执行的证明。静态提示和模型输出状态如实区分。
5. B6“当前重点群体”必须来自 B4 已保存的真实维度/群体选择；参考数字来自该群体当前对比窗口的服务端复核结果。不得填“近30天新生”等资产中不存在的人群，也不得编造“低于整体”或其他未经计算的比较。上游缺失或过期时显示原因与返回入口，不补假上下文。
6. 概念中的数字、选中项和完成状态仅示范结构。未运行时显示可读空态；运行后显示真实结果。修改窗口、分母或上游选择后保留历史但明确失效，不能当作当前结果。学生解释、假设、行动描述及验证计划初始为空；恢复时仅回填本人真实已保存内容。

B6 的目标显示“所选群体对比期基线＋学生期望提升”，单位为百分点，不称预测收益；比率目标不得超过100%。支持护栏显示“次/100人”，不是百分比，允许大于100。基线分母为0时显示“尚无可计算基线”，引导更换指标或窗口，不填0。

28/42天复盘从最后一名试验参与者入组日算起；统计均只覆盖每人入组后前28天。42天表示晚14天复盘，不是把42天累积值与28天基线比较。图中简短提示需展开为这一真实口径；选择状态以实际表单和保存结果为准。

## 3. 可视化与交互实施清单

| 视图 | 主要表达与原生控件 | 口径、状态与完整替代 |
| --- | --- | --- |
| B2 指标 | 分子/分母选择、两组开始/结束批次、计算按钮；两期数值表与12批次趋势 | 展示分子、分母、比例和单位；改变条件分母后标题同步变为“已开始学习者完成率”。批次是入学批次，不是事件自然周；先合计再计算，不平均周比例。 |
| B3 漏斗 | 六阶段两期横向条形对照；五个相邻环节的精确表；排序控件、重点选择与理由 | 累计图共享0–100%轴，显示人数；相邻表显示上一环节分母、到达人数、转化率、损失人数和变化百分点。排序标明口径，不改变计算或自动替学生选重点。 |
| B4 细分 | 课程/来源单一维度选择；两期群体表与一个主对照图；优先群体及理由 | 同时保留报名量/占比、主指标和 B3 所选环节的分子分母；六阶段计数支持 B6 基线。切换维度清除失效群体选择，支持联系次数独立呈现，不成为漏斗阶段。 |
| B5 假设 | 观测、来源步骤、可能原因、未知信息分区输入 | 学生原话属于未核验分析，不由系统补成事实或宣布因果成立；引用当前 B2/B3/B4 证据，不假装存在原因预测。 |
| B6 行动 | 上游摘要、行动选择/描述/依据、成功指标与目标、护栏上限、复盘单选和验证计划 | 目标与实测基线分开。当前群体、窗口、单位和来源始终一致；缺少基线、上游失效、范围不合法时给出可恢复说明，不生成预计挽回人数。 |

渲染使用 Vue 管理 SVG DOM 与原生 HTML 表格，统计由固定 Worker 预览和服务端白名单重算提供，不在图表层重新定义指标。累计和分组对照使用一致单位、刻度、窗口、分类顺序与蓝/灰两期编码，同时保留文字图例。绝对比例和人数条形从零开始；不做3D漏斗、面积隐喻、双轴、截断比例轴、自动动画或原因高亮。

每屏一个主图，精确结果有完整原生表格替代，不强迫依赖鼠标悬浮。零人数、零分母与无结果分别展示；null 不画成0，基期率为0时相对变化显示不可计算，不显示无穷大。变化百分点与相对变化百分比分开标注，不混用。

SVG 有 title/description，表格有列标题；控件有 label、键盘操作与清晰 focus，帮助及数据表可键盘展开。保存中、保存失败、CAS冲突、执行失败、额度耗尽、相同配置复用、结果过期、暂停恢复均复用既有工作区状态，不另外制造一套浏览器真相。30种成功配置上限与 HTTP 限流区别提示。

1024–1100px 沿用帮助抽屉；小于1024px保留明确设备限制，不通过压缩字体或表格绕过编辑边界。长解释、完整表格与 B6 验证计划通过中心滚动区容纳，底部按钮不得遮挡输入末尾。390px窄屏验证的是设备提示与导航可达，不宣称支持完整移动端编辑。
