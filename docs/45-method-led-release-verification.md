## 实现范围

| 内容 | 新版实现 |
| --- | --- |
| AI | 从分类小例子与比例入门，到找出错分模式、有限调整、固定集比较、说明取舍，再换一题解释自动处理和人工复核 |
| DS | 从一行数据代表什么入门，区分重复／未开始／空白，下载 Excel 做清理、分组和课程内比较，说明关系不能证明原因 |
| BA | 先分清分母与批次，沿学习流程选问题和群体，区分观察与原因，选择补信息或小试验，再解释新情境中的因果限制 |
| 过程记录 | 三专业各六步、三个关键检查点；显式初次提交、一次修订、帮助与恢复说明，一个可明确跳过的新情境题 |
| 本地数据 | 下载版本绑定的 `.xlsx`；回填规则、数值和理由。保留原值，可复算范围才给核对结果；不上传整份文件、不推测本地操作 |
| 报告 | 完整相关上下文 → 高能力模型初稿 → 必经独立审阅 → 覆盖、归属与原话检查 → 不可变版本；比较报告同样处理 |
| 阅读 | “这次你做了什么／沿着过程回看／这与专业选择有什么关系”；具体原话与解释，全部回答可展开，打印保留细节 |

概念回答错误不会阻止体验继续；需要补填、明确提交或核对的操作会滚动定位并突出显示。使用系统计算的结果会单独记录，不能计为独立完成。已说清的回答允许没有额外改进建议；需要补充或改正的回答仍须给出具体下一步。

## 真实模型质量检查

本轮使用 `qwen3.8-max-0902` 的完整上下文与思考模式，初稿及独立审阅分别调用。报告专用超时上限 900 秒、思考预算 32768、输出上限 32768；不继承任务提示的短预算，不静默换小模型。最多初稿、一次结构修复、一次审阅，共 3 次请求。正常测试不调用付费接口。

严格结构化输出与服务器覆盖校验并用；能力依据见 [百炼结构化输出官方文档](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/qwen-structured-output)。实际账号支持和项目质量仍以本轮调用结果为准。

已发现并处理的工程／表达问题：

1. 早期输出省略节点和逐题分析：请求端显式约束本次节点数、回答数与允许引用集合；服务端继续独立拒绝漏项。
2. 模型把提交阶段误解为职业角色：提示明确首次、修订、新情境不是不同专业或不同人。
3. 报告重复原话和下一步：节点解释使用短段，原话、变化和建议由页面分别呈现。
4. 正确回答被迫凑建议：仅这类回答允许空的额外建议；错误、缺项或无法判断仍须说明下一步。
5. 最终答案被误当修改记录：v5 请求按检查点列出真实提交阶段、可用变化状态及精确引用；变化引用 Schema 只允许明确提交记录。独立审阅仍必须进行，失败不发布。
6. v5 的 Q09 虽通过结构检查，逐句代理复核发现把“未完成”误写为应排除在完成率分母外，并把无法复算本身作为回答不完整的理由。本例明确记为语义失败，未开放主站。v6 独立审阅增加分子／分母、验证范围与回答质量分离、建议重复及无依据困难的复核；新批次重新执行，不能沿用 v5 的通过数。
7. v6 的 Q04 仍将三个答非所问的本地说明标为有依据，依据却是邻接的核对数值；另有 Q01／Q09 把未观察到本地操作或其他步骤缺项混入当前文字判断。v7 进一步要求逐条评价被引用的文字，数值核对与说明质量分开，节点限于自身检查点及真实新情境。v6 不作为最终质量批次。
8. v7 的 Q04 仍未解决上述三个文字误判，已明确留存失败审阅。v8 在完整原始输入之外，增加仅审阅阶段使用的逐题目录：精确题目、原话、评价对象和各节点实际标准，先独立重判文字再对照草稿；不只延长笼统提示。先用 Q04 单例验证，未通过不能切主站。

### 内容质量的已知局限

核心案例预期通过与完整语义正确是不同结论。逐例记录保留如下观察，不能在交付时删去：

- Q04 的无关开放回答已全部识别为无法判断，没有虚构学习进步；但三个节点的总体标签偏严，正文说“没有相关解释”而标签为“需要改正”。正文边界正确不代表标签已最准确。
- Q06 能指出两处分母问题、分别认可后续正确判断，没有推断稳定能力；但对上游分母问题与后续选择的联系表述仍偏保守，尚未把两处问题串成最清楚的说明。
- Q09 能认可自定义处理方法，不因无法复算而惩罚理由，但模型正文对数值未核对的表达仍可更明确。页面另以冻结记录生成的核对事实显示真实状态；模型文字不能代替这一事实。
- Q13 的跨专业引用和不排名边界通过；某条比较用“原因”总括 BA／DS 的因果限制与 AI 的泛化限制，细项各自有依据但总括不够严谨。“分母意识稳定”也只能理解为本次几道题的表现，不可外推为稳定能力。
- 正确回答有时仍收到与原回答重复的可选建议，不应被读成额外必做题或本次回答错误。后续真人可读性检查需一并精简。
- Q08 的“差距是否足够明显”建议仍偏模糊；Q11 一条逐题建议的消息分类不够互斥，节点正文则分为自动且分对／自动但分错／人工。Q12 没有把未教授的高级统计要求当作学生缺陷，但也未显式指出内容设计冲突，不能宣称自动教学缺陷告警已通过。

因此离线质量门禁明确输出 `semanticCertainty: false`、`humanComprehension: NOT_RUN`；它核对当前输入／模型／提示／输出和代理审阅记录，不认证专业教学质量或目标学生理解。
