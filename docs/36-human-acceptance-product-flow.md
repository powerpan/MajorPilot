2026-09-21。状态：本地实现、真实报告和端到端流程验收通过；交付提交以 Git 历史与本次对话回执为准。范围是用户明确提出的四项验收反馈，不扩展为 P8 全部交付，不公开部署。

## 本轮决定

1. 学生主入口不再提供“工程预览”。AI / DS / BA 经逐版本本地授权后进入完整产品流程，接续真实报告、下一专业与比较。内容仍可处于 REVIEW；不伪造专业审核或真人计时结果。
2. “下一步”缺少必要操作时，平滑定位到具体字段、批次、运行按钮或确认处，显示局部解释和短暂高亮。尊重减少动态效果偏好。服务端校验、草稿保护、执行版本绑定均保留。
3. 主推荐栏右侧提供开始／继续／查看报告按钮。新开始仍记录真实推荐决定；有其他进行中体验时先明确确认暂停切换。手机只读体验进度与报告，不悄悄开启桌面任务。
4. 对本次已完成的 BA 体验，以原有冻结输入与 READY 证据快照生成真实私有报告。保留原始 REVIEW_PREVIEW 来源；不编造任务答案、不补做点击、不重写历史。

该请求明确修订旧文档中“预览永不进入报告”的绝对边界。默认未授权预览仍不能生成报告；例外仅限精确、审计化的历史接入。详见 [ADR](./adr/0001-local-product-release-and-historical-evidence.md)。

## 数据与权限

- V9：`mp_local_task_release` 固定任务 hash；`mp_run_product_adoption` 固定 Student / Run / Task / Profile / closed input hash。迁移只建结构，不授予任何内容或记录权限。
- 本地内容授权需 `majorpilot:task:publish`；历史接入同时需恢复与报告再生成权限，并受本地产品开关限制。
- 原始关闭记录、反思与证据 hash 校验通过后，才在同一 Student 锁与事务中建立 NEXT、报告与队列。重复请求幂等；不同授权引用、版本冲突、跨主体、同专业冲突均拒绝。
- 新历史接入若已有其他 CLOSED 产品体验，返回 `PRODUCT_ADOPTION_ORDER_CONFLICT`，避免改写既有 NEXT 历史。已接入的相同授权重试不受后来完成其他专业影响。
- 历史来源在 ReportInput 中保留原 runMode 与内部授权证明；报告公开 DTO 和模型输入不暴露内部授权信息。发布时重新验证，不以请求提供的证明自行授信。
- 个人删除、导出、推荐排除已完成方向、比较来源均纳入新边界。原 metrics-v2 口径不改写。
- 真实模型测试由用户明确授权；普通回归仍不触发付费调用。API Key 仅保存在忽略的环境文件。
