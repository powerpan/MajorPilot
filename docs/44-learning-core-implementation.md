# 方法主线改版第二批：数值核对与过程记录内核

2026-09-24。实现依据：[39 案例](./39-guided-major-case-specifications.md)、[40 过程证据](./40-learning-evidence-and-report-design.md)、[41 本地结果](./41-excel-download-and-local-results.md)。本批是可测试的纯领域代码，不是已经开放的接口或新版网站。

## 已实现的职责

### Local Result Submission 数值核对

[LocalResultVerifier](../backend/ruoyi-majorpilot/src/main/java/com/ruoyi/majorpilot/learning/LocalResultVerifier.java) 不打开学生文件、不请求本地路径、不调用模型，只接收服务端选定的公开数据、受信任版本绑定和学生明确提交的结果。

- DS 支持保留全部记录或删除完全重复记录、按原始行ID明确排除、保留未开始者与缺失的不同含义，在已开始且天数有效的人中按0–3／4–28天比较，并按课程再次比较。可声明其他合法天数范围；比较定义随输入保留。
- 去重只删除字段全部相同的行，不将同一学员ID的不同记录误当完全重复。处理顺序固定为“原始行排除 → 完全重复处理 → 明确比较范围”。保留人数和唯一学员人数分别返回。
- DS 分清理、总体比较、课程内比较三个结果组，分别只要求3、6、12个相关数值，不把全部25项后台诊断都变成一张必填表。
- BA 支持明确的不重叠批次、课程／来源筛选、相邻环节，以及以报名者或已开始者为分母的完成比例。先合计人数再相除；百分点、相对变化分别计算。联系次数按每100名报名者计，不称人数百分比，也不限制为不超过100。
- 计数精确核对；小数保留学生原字符串及精度，32与32.4不被混成同一舍入标准。比例采用分数直接按声明精度舍入，避免统一容差掩盖分母／单位错误。
- 零分母是无法计算，不能填0冒充；未知版本不按当前文件强行核对。“其他方法”返回 `NOT_REPRODUCIBLE`，技术不可用返回 `NOT_CHECKED`，都不代表学生答错。
- 原值、重算值和逐字段差异并存，不自动改写学生结果。解释是否成立仍需逐项分析；`MATCHED` 不证明理解、Excel熟练或独立完成。

AI 的公开错例引用、配置改变和固定评价集绑定仍使用既有分类器边界；本批不假称新增AI回填接口已经完成。

### Learning Attempt 过程规则

[LearningTimeline](../backend/ruoyi-majorpilot/src/main/java/com/ruoyi/majorpilot/learning/LearningTimeline.java) 定义明确提交、支持提供、选择系统中间结果、带支持继续四类记录。

- 一个方法版本恰有3个理解检查点，每点最多初次和一次修订，全专业只有一道单独的新情境题。没有正确率或掌握等级。
- 草稿自动保存不进入此边界；只有明确提交才记录尝试。后续修订新增记录，不替换首次回答。
- 基础讲解需先提供；记录用“提供过”，不声称读过、学会或没有外部帮助。新情境可以缺失，不伪造前后变化。
- 系统中间结果另记为 `SYSTEM_RESULT_SELECTED_NOT_STUDENT_WORK`；下游尝试保留此前已提供支持的序列，包括上游恢复条件。
- 修订比较同一步的响应revision；新情境题在另一小步时不错误要求其revision大于前一步的revision。
- 每条记录绑定Run、任务manifest、方法定义、源响应revision／hash，以及上条记录hash；顺序冲突、重复角色、陌生帮助、交换顺序、改原话、改时间、跨Run搬运或改方法定义均被拒绝。
- 冻结要求3个初次提交存在，但不要求答对、修订或答迁移题。旧版Run没有这些记录时不能调用本内核捏造过程。

## 接入边界与仍待完成的工程

内核不是鉴权或数据库层。不得直接把客户端传来的绑定、响应hash或时间当作可信事实。

后续应用层必须按以下次序接入：

1. 验证活动Student及其Run归属，校验任务版本支持该方法；旧任务不自动升级。
2. 使用既有Student事务锁、幂等服务和Run／Step revision，读取服务端固定资产与原始响应。幂等重放先做当前授权检查，不被后来revision误拒绝。
3. 保存本地回填原值再核对；失败保留已保存记录。执行核对和重试不能默默覆盖既有核对结果。
4. 从服务端生成提交序列／时间与版本绑定；新增持久化记录，禁止覆盖历史。提供支持的记录必须与实际返回该材料绑定。
5. 同事务关闭Run并冻结最终回答、过程记录、回填、支持、反思与版本。异步报告只能读取冻结集合。
6. 同步个人导出、删除归属图、留存、后台安全查询和故障恢复测试；不能只新增表而遗漏隐私责任。
7. 采用新迁移。工作区原有V10／V11及报告v2尚未验收，不能通过随意启用整棵工作区或越过迁移顺序上线。整合与隔离迁移测试完成前，本批不改变主数据库V9。

方法案例版本、持久化／API、网页引导与回填、新报告冻结／模型审阅／三层阅读尚未接通。不能因为内核单元测试通过就把这些项目标记完成；当前入口仍是1.0.0案例加Excel下载。

## 验证证据

普通入口：`sh scripts/test-learning-core`。12项数值核对测试与10项过程规则测试通过，均不调用模型、不连数据库、不修改学生记录。

仅含本批暂存代码的独立树 `0477dd238fb264a8b1daa1fb3988803b7e050859`（本机临时构建目录 `/tmp/majorpilot-learning-core.NukU9O`）重新编译后，22项新增测试及13项工作簿／旧内容回归共35项通过、零失败、零跳过。该树的66份Markdown／401个本地链接及14份归档还原检查通过；不依赖工作区未提交的报告v2代码。其后只追加本段验证说明。

独立对公开资产复算并固定的代表事实：

- DS 完全去重后359行，未开始51行，已开始但等待天数缺失8行；可比较的早开始组100人／完成58人，晚开始组200人／完成93人。这只描述指定数据与处理方法，不证明早点开始导致完成。
- BA 第1–6批报名180人、完成100人；第7–12批报名179人、完成58人。分别为55.56%与32.40%，变化−23.15个百分点；相对变化−41.68%。每人观察入组后28天，不是同一批人前后变化。
- 测试覆盖全部5对相邻环节×3个课程范围×4个来源范围、舍入边界、无匹配组、零分母、重复行、null／0、0／3／4／28／29天、未知版本、其他方法、失败未核对、原值及防御性复制。

这些是软件与数值检查，不是Q01–Q16模型语义门禁、真实新手试用、原生Excel兼容或专业内容审核。
