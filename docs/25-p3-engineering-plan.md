# P3 AI 专业闭环实施接缝

> 2026-09-21。基于既有09/10/11/16专题设计推进，不改变分类算法、报告边界或真实用户出口。P2已推送 `02e755203ac7c4afe49bba45a6ee5f0acd14b78b`，已核对远端main一致。

## 1. 不变范围

AI使用LumenLearn合成支持请求情境，A1–A6加固定Reflection。采用公开说明的 `classifier-v1` 教学分类器，不把在线大模型回答当隐藏集评分，不声称训练了大模型。公开练习在隔离Worker预览；A4保存配置，A5正式评估由服务端读取A4固定revision重算。最多5种成功配置；baseline和相同规范化配置复用不扣次数。隐藏标签、逐条对错和私有资产路径均不得下发。

## 2. 本地工程预览与正式发布

真实目标用户计时与内容审核证据当前不齐。专业内容保持 `REVIEW`，绝不伪填 `TIMING_45_60=true` 或自动 `PUBLISHED`。为继续本地工程验证，增加明确分离的 `runMode=REVIEW_PREVIEW`：

- 仅loopback `local` profile、显式默认false的 `MP_CONTENT_PREVIEW_ENABLED`、已验证Student身份可访问；与现有本地账户沙箱同范围，无公共预览路由或隐式生产开关。
- 预览入口只读取已校验REVIEW版本；`contentKind=MAJOR`、真实major保留，不冒充DEMO。所有页面标注“工程预览；尚待专业审核与真实用户计时”。
- `STANDARD` 为旧运行默认值；预览状态持久化，进入事件与关闭manifest，内容以后正式发布也不能把旧预览升级为正式体验。
- 正式专业可用性、完成集合、NEXT与专业报告只计算STANDARD；预览不伪造推荐决定，不进入正式推荐/完成计数。活动槽约束仍跨所有模式；预览有独立lane，避免阻挡之后的正式首次体验。
- 预览可真实保存、执行、暂停、关闭，并构建标注预览的内部Evidence Snapshot；用户端报告 `NOT_APPLICABLE`，不显示虚假排队。正式关闭与报告流水线通过精确隔离的合成测试fixture验证，不将测试数据发布到主库或伪称真人已审。

这是工程验证能力，不替代产品正式发布门禁，也不改变用户未来的正式三专业体验流程。

## 3. 版本化接缝

- 新 `task-manifest-v2` 支持受限可空数值、classifier配置/结果合同及跨步骤输入绑定；保持已发布v1及V4/V5不变。
- 规范化配置按冻结标签顺序排列定义变体、对示例ID集合排序，剔除解释文本/revision后再哈希。保存原来源revision与当前应用绑定；末端再次校验，拒绝计算期间输入已改变的结果。
- 72条支持消息（24公开练习、48隐藏评价）使用独立训练/候选示例ID，四标签隐藏评价各12条。实际数据和完整黄金向量需由生成产物复算，不以设计演算替代验证。
- Java/JavaScript共享黄金向量：Unicode/NFKC/双字符、6位half-up（负中点远离0）、舍入后softmax、同分固定标签、恰好阈值、全部转人工、零分母null、示例伪计数和配置集合顺序不变。
