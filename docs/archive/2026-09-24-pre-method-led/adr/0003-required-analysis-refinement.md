# 报告发布前必须独立审校改写

2026-09-21。旗舰模型在完整材料和加强准则下，仍可能在结构合法的报告里误读比例、来源或试验目标；仅继续叠加首轮提示词未达到本轮质量门槛。因此新报告须经过初稿生成与独立审校改写，审校仍读取完整原材料，返回完整修订稿，而不是一句“通过”。不以此宣称模型已经证明自然语言分析正确。

两阶段使用明确选定的报告模型，不在失败后静默换成低价模型。版本请求固定审校策略；私有草稿、审校输入、最终候选与原来源分别进行哈希绑定，只有同一来源下成功完成审校并再次通过本地合同与引用验证的候选才可作为 AI 分析发布。共享时间与次数预算，初稿最多一次结构修复，审校不重试或再修复。在途进程中断被记为未知，不重复调用；持久化草稿可恢复到审校，已验证最终稿可直接恢复发布。

代价是更长等待、更多模型用量以及额外恢复状态；本轮优先保证分析质量与可追溯性。失败的增强不得替换已有可读报告，首次失败则明确分析不可用。旧报告、原答案与已执行迁移不改写，人工语义验收依然独立于模型自检及程序验证。
