# 在生成前绑定评价对象，而非让模型重抄来源

2026-09-22。真实完整报告在深分析时反复发生题目与引用错配，而相同完整上下文的纯绑定任务能够正确对应全部原话；增加映射提示仍只能提高遵循概率。因此新通信合同在请求前，由已验证来源确定题目、答案及连续原文片段，模型选择明确的评价对象和片段，输出分析及可选支持来源；程序只按这份冻结的一一映射展开，不在模型错引后猜测或补造来源。

新合同覆盖全部已提供的步骤开放题，未知、重复、跨归属、漏题和非法片段均拒绝；长答案保留全文供分析，展示引文选自预先冻结的片段，不静默截断或改写。初稿、修复和审校使用相同版本和绑定规则，映射进入模型输入哈希，旧合同及已保存报告仍可重建。代价是额外的版本化协议和双向转换；它移除确定性抄写负担，但不能证明模型对正确题目给出了正确分析，独立审校与真实语义验收仍须保留。
