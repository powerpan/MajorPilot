# 从固定声明选择升级为有来源的作答分析

2026-09-21，用户指出真实报告无法识别开放题中的概念错误、无依据目标或敷衍回答，并授权完善。v1 将“不把学生说法当成事实”实现为“不让模型阅读和评价学生说法”，导致真实 API 调用也只能选择固定文案。v2 保留可重算事实、原始来源和不评判长期能力的边界，但允许高能力推理模型评价本次作答，输出原文引用、理由、改进建议与示例；服务器验证合同、引用和范围，不宣称这些检查能证明任意自然语言完全正确。

新分析引用不可变 Evidence Snapshot，或关闭时已固定并重新校验的 Frozen Response Reference；后者补齐旧提取规则遗漏的原答案和反思，不伪造 Evidence Item、不把未验证答案升级为事实。新版本采用独立合同和规则，保留旧报告与原始答案。固定目录继续承担事实展示与故障回退，不再冒充深入分析；内容质量必须通过真实模型对照验收，而非仅通过 JSON 或流程测试。
