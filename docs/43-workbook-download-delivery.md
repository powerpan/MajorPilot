## 兼容性决策

不放宽旧任务 JSON／CSV／文本白名单，也不改历史 manifest 及数据库 pin。增加独立的、受控的派生工作簿目录；每份只对应原版本和明确公开来源。新案例发布时必须新增登记，不复用旧文件冒充新版本。这个兼容层是先行交付，并不将旧案例升级为方法主线新案例。

真实路由沿用项目身份 Cookie 的路径，而不是41中的概念示例：

- `GET /api/app/v1/experience-runs/{id}/workbooks`
- `GET /api/app/v1/experience-runs/{id}/workbooks/{assetKey}`

完整增量合同见[OpenAPI](../contracts/openapi-workbooks.json)。先核验活动账户、本人 Run 和可用的绑定内容，再返回元数据或附件；暂停／关闭状态不阻止读取本人的可用原材料。只接受登记的 `materials`，不接受路径、URL、私有键。响应是实际 OOXML、UTF-8 附件文件名、准确长度、`no-store` 与 `nosniff`。不改变进度、配额、Run、报告或已执行迁移，不触发模型。

加载阶段核验有界 ZIP 和全部 XML：限定包内文件、数量／展开大小，拒绝宏、外部关系、隐藏 sheet、目录穿越、任意公式和外部实体。只有练习区明确的比例教学公式允许存在；原始数据没有公式。逐格测试另核对公开原始数据及AI材料没有私有来源标记。文件名和包路径均来自服务端固定元信息。
