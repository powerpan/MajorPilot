# P6 报告与比较视觉合同

> 2026-09-24 新版本采用[40的三层阅读结构](./40-learning-evidence-and-report-design.md)：先体验概览，再方法过程，最后专业连接与下一步；不再强制将原九节与逐题分析重复堆叠。原九节的信息责任仍有对应位置，编辑式阅读、可访问性、私有访问与打印完整性不变。下文截图和验证属于旧版，不是新设计的浏览器或打印验收。

> 2026-09-21：依据[已锁定的 P6 工程设计](./31-p6-engineering-plan.md)与[页面流程中的报告约束](./14-ui-flow-and-wireframes.md#13-experience-report)实施并逐项验收。下列四张概念图已与实际页面同轮查看；这不表示用户逐图批准，也不替代真实专业内容审核。网页流程已通过，打印修复的最终证据见第4节；正式链路使用隔离 TEST_FIXTURE，不开放工程预览报告。

## 1. 关键屏与原生阅读结构

- [单专业报告概览](./design/p6-report-overview-v1.png)：开放式长文、左侧章节导航、报告元信息、事实与自述、可展开依据和边界说明。示例使用 Data Science，不限定其他专业沿用其正文。
- [下一项建议与反馈](./design/p6-report-next-feedback-v1.png)：两个专业工作方式的差异、规则生成的下一项建议、自由改选、可跳过反馈。反馈控件需按第2节修正后实现，不能完整照抄图片。
- [专业体验比较](./design/p6-comparison-v1.png)：固定来源版本、按共同维度并列的文字比较、仍然未知之处及下一步验证；没有总分或获胜专业。
- [手机报告阅读](./design/p6-report-mobile-v1.png)：单列长文、章节跳转、打印入口、文字标签与展开依据。图片尺寸为853×1844，约为390×844视口的倍图；不能把图中像素直接当 CSS 字号和间距。

页面使用原生 Vue/HTML 纯文本、标题、段落、列表、表格、按钮和折叠区域；概念图不进入产品页面，不做截图式 UI。不新增图表、评分仪表盘、卡片网格、雷达图、专业排行榜或模型自由正文渲染。报告页是阅读 shell，不复制任务编辑页的右侧提示栏、操作配额和固定“完成此步骤”按钮。

单专业报告必须完整覆盖九节，顺序来自真实 API：体验概览、你完成了什么、体验偏好、当前准备度、本次任务表现、专业工作方式连接、证据和结论边界、另外两个专业的差异、下一次体验建议。比较报告必须覆盖八节：比较范围与来源、各自完成的工作、自述体验、共同维度、专业特有体验、仍然未知、下一步验证、剩余专业。概念只截取其中一部分，未显示的章节不是可以省略的功能。

## 2. 视觉系统与必须落实的准确性修正

延续 MajorPilot 纸色 `#F7F5EE`、墨黑 `#171A1D`、蓝 `#304FFE` 与克制的橙 `#F45B35`；复用既有品牌、无衬线正文与衬线展示标题体系。桌面为简洁顶栏、左侧目录、宽松正文列，细灰分隔线和开放留白，不将每条结论包进独立卡片。蓝色用于链接、目录当前项和文字标签，橙色只作既有专业或强调编码，不表达“更适合”。

大标题、章节标题、正文、元信息与操作控件形成稳定层级；桌面正文约18px，控件至少16px，辅助文字不以过小字号弱化边界。移动端按真实390/768px视口重新检查可读字号、自然换行和触摸区域，不机械缩放整张桌面图。品牌、个人主页和打印入口保持可见可达，长英文专业名允许合理换行。

概念到实现必须修正以下事项：

1. 概览图左目录的“你完成了什么”为02，正文却标01。实际以九节统一序号和锚点；若正文省略数字，则整套正文一致省略，不能保留冲突序号。比较页目录也按八节真实结构生成。
2. 反馈图评论计数 `0 / 500` 改为 API 合同的1000字上限，输入、计数、校验与错误提示一致。不得借视觉稿降低或悄悄扩大合同。
3. 两道1–5题都显示清晰完整的 **1、2、3、4、5** 数值与可访问标签，不能只有两端文字配五个无标记圆点；默认不选择答案。题目是“是否获得新的认识”和“选择方向是否更清楚”，不得将端点描述误当整份报告适配度评分。
4. 反馈补齐 `report-value-v1` 的下一步意向：尝试另一专业、进一步了解当前方向、暂缓决定、其他、不愿回答，对应合同枚举。每题可跳；提交问卷时至少一项有效答案，不自动把未答题填成中间值或负面值。“跳过，继续探索”不补造反馈，也不阻止下一项体验。
5. 任务/报告版本、生成日期、专业、支持条件、事实、自述、克制解释、NEXT 和比较来源必须来自当前身份授权的真实 API。图里的例值和“布局示例，不代表真实学生报告”仅属于概念，不进入真实产品正文或页脚；真实报告仍保留“体验总结，不是适配度测试或录取判断”等必要边界。
6. 比较来源引用固定的单专业 Report Version。仅当该来源仍是对应报告的当前可读版本时，才提供准确的查看链接；若来源已被替代，显示“本比较依据报告版本 X，单项报告已有更新”等固定版本说明，不提供历史正文入口，也不把通向新版的链接伪称原依据。点击与读取间发生版本变化时，同样明确提示，不能静默展示不同来源。
7. 概念中的“你愿意继续”“已完成数据质量检查”和具体推荐仅是布局样例，不能用于空态或占位。真实解释受 statement/phrasing 目录、证据允许类型和本次体验范围限制；前端不得自行总结、补写、改写因果或将学生期望当真实收益。

“事实／你的自述／本次解释／限制／下一步”同时用文字标签与排版区分，不只依赖颜色。查看依据只展开服务端筛选的简短说明，不显示 evidence ID、数据库键、hash调试值、完整日志、私有数据行、隐藏标签、学生未核验分析原文或提示词。无可用解释时保留真实事实、自述和限制，不用填充段落凑满版面。

## 3. 阅读、建议、反馈与状态合同

### 3.1 依据与比较

每条可展示依据的结论有键盘可操作的展开入口，展开后就在所属条目下显示来源摘要，收起后焦点合理保留；无悬浮才能读取的必要信息。长摘要、空证据维度和较长专业名称都应完整换行，不截断成失去限定词的断言。

比较只使用已固定来源的七个共同维度：问题类型兴趣、定量信息舒适程度、不确定信息处理、对模型/数据/行动决策的关注、遇到困难时的求助和迭代、解释表达结果的兴趣、继续类似任务的意愿。概念表格仅展示四行，不是将合同缩为四维。证据不足显示“本次尚无足够证据”；不依据操作成功、提示次数或相关系数填出能力评价。

桌面可用语义表格或对齐的开放列，来源及不同专业始终可辨；第三个专业进入时保持同一比较结构，不添加获胜色或排名。手机按**一个维度→各专业对应内容**逐项堆叠，不能先列完一个专业再列另一个，也不能要求横向滚动宽表才能比较。

### 3.2 下一项与反馈

下一项区域显示冻结规则理由及工作方式差异，保留“了解下一项体验”和自由改选入口。建议不是能力排名；推荐排序与当前可用性分开呈现，不因内容暂不可用改写历史推荐。已暂停项可继续原进度；三个正式专业均完成时显示完成后的探索说明，不重新推荐已完成方向。仅阅读介绍不创建 Run，反馈也不成为接受推荐或开始体验的前置条件。

反馈紧随阅读内容，用简单原生字段而非弹窗拦截。可选评论不提示填写隐私信息；诊断信息只有明确同意才附带。提交时固定正在阅读的本人报告版本，成功就地确认、清除对应草稿，失败保留可恢复输入；同页新版本发布后仍可将反馈归属于已读的本人旧版本，但这不授权读取历史正文。不得将反馈解读为更改本次报告、反思或推荐。

### 3.3 未绘制状态沿用简洁阅读 shell

| 状态 | 原生呈现与安全动作 | 不可做的事 |
| --- | --- | --- |
| 首次加载 | 少量无语义的布局占位或“正在加载报告”，保留返回个人主页 | 用示例事实、分数或假进度装作报告 |
| 证据准备／报告生成中 | “体验已完成，报告正在准备。你可以安全离开，稍后回来查看。”显示服务端安全状态、状态刷新与返回入口 | 暗示必须重做任务；伪造完成百分比或确定完成时间 |
| 基础报告已就绪 | “部分个性化解释暂不可用；事实、自述和本次成果仍可查看。”沿相同九节/八节阅读结构呈现 | 把回退标为模型成功；显示无权限的 bounded 解释或供应商错误 |
| 无可用报告且生成失败 | “体验已完成，报告准备异常。请稍后刷新状态。”提供状态刷新与安全返回 | 用缺失证据生成正文；状态刷新暗中触发付费重生成 |
| 有旧 current，新版本处理中／失败 | 继续展示当前已发布正文与版本信息，另给克制的更新状态 | 用空白页或失败提示替换仍可读的报告；展示未验证新正文 |
| 比较来源不足／仍准备 | 分别说明尚需另一个专业、等待来源报告、来源失败或比较正在生成，并给实际可用入口 | 把两次同专业体验算成两个专业；拼凑未就绪摘要 |
| 新版本／打印冲突 | “报告版本已更新，请刷新后再打印。”不改变正在阅读的内容而不告知 | 静默打印与页面不同的版本；开放旧版读取后门 |
| 网络异常／会话过期／无权限 | 区分可刷新网络错误和需重新登录的状态；登录后重新校验归属再加载 | 退出后保留前账户正文；泄漏其他人报告是否存在 |

状态刷新只是读取；前台轮询遵循工程合同并逐步退避，页面隐藏后停止，不生成虚假阅读事件。反馈成功、展开/收起、加载错误采用克制的可访问提示，不以反复弹窗打断阅读。报告没有通用“学生重生成”按钮，管理端重生成权限不能通过阅读页绕过。

### 3.4 手机阅读与私有打印

报告和比较支持手机阅读，不继承任务工作区的小于1024px编辑限制。窄屏收起桌面目录，使用带可见标签的原生章节跳转或等价可访问导航；依据展开、反馈、个人主页和打印入口仍可操作。768px检查平板阅读布局，390×844检查单列、换行、触摸目标、键盘弹出和长评论；无全页横向溢出。由报告跳往任务时，仍遵守任务编辑设备限制。

打印走相同已验证身份和当前版本规则，提交预期报告版本校验；没有免登录打印链接、公开分享 URL 或历史版本查询参数。打印页面包含真实 reportVersionId、版本号、生成日期和边界说明；纯文本、原生标题与表格适配纸面，去掉目录导航、反馈输入和不适用操作。必要的依据摘要与限制不能因折叠/分页消失，不将标题孤立在页尾或截断跨页表格。浏览器保存 PDF 只是用户自己的打印结果，不代表公开发布。

报告正文不进入 IndexedDB、localStorage、Service Worker 或公开缓存；退出/换账号立即清除当前阅读内存并重新鉴权。仅允许工程合同规定的本账户、反馈上下文、7天TTL评论草稿，成功即清理，不缓存报告全文。研究同意不是核心阅读权限，撤回研究同意不能隐藏仍合法可读的报告。

## 4. 实施后门禁与实际证据

实现后需同轮用 `view_image` 对照这四张概念和最新真实截图。桌面概念为1536×1024，另测1366px；手机概念是853×1844倍图，实际必须验证390×844和768px视口，不能用图片比例推断响应式已通过。未绘制的状态按第3节原生阅读 shell 核查，不以缺少状态图为由省略功能。

| 检查项 | 必须留下的验证证据 | 当前状态 |
| --- | --- | --- |
| 1. 内容与来源 | 九节/八节齐全，序号一致，正文/日期/版本/NEXT来自真实API，概念例值无残留，旧比较来源不误跳 | Chrome/Edge 实际 HTTP 与浏览器通过 |
| 2. Shell与排版 | 开放长文、章节目录/跳转、顶栏、依据展开、长摘要和三专业比较不变成卡片网格 | 主代理同轮概念与实际截图对照通过 |
| 3. 字体 | 衬线标题/正文层级、真实CSS字号、中文及长英文换行，390/768不机械复制倍图字号 | 桌面标题62/章节36/正文18px，手机标题36/正文18px，控件至少16px；通过 |
| 4. 色彩与标签 | 既有token/品牌，事实、自述、解释、限制的文字区分；无适配分数、排名或胜负编码 | 实际截图与字段投影检查通过 |
| 5. 控件与路径 | 章节跳转、依据、NEXT改选/可用性、完整1–5选项、可跳下一步意向、1000字评论、成功/失败草稿 | 两浏览器业务矩阵与键盘测试通过 |
| 6. 版本与私有打印 | 本人当前报告、版本冲突、无历史后门、页脚和来源一致、纸面分页及必要依据完整 | 实际单专业3页/比较6页，全部正文/依据/页脚及21格PDF检查通过 |
| 7. 状态与恢复 | 等待/失败/回退/旧版仍可读/比较不足、刷新不重生成、会话过期/退出隔离、真实零证据处理 | 两浏览器实际 API 流程及无账号状态布局补检通过 |
| 8. 响应式与可访问性 | 桌面及390/768阅读、比较按维度堆叠、无横溢出、键盘/focus/触摸目标、reduced-motion与打印阅读 | 1536/1366/768/390 网页与修复后的独立纸面验收通过 |

真实 Chrome153.0.8010.48/Edge151.0.4129.78 功能验收日志为 `/tmp/majorpilot-p6-browser-final.log`。9/8节、两专业14格到三专业21格、NEXT介绍不创建Run及暂停恢复、固定来源版本冲突、跨账号/退出/会话过期均经过实际后端；无账号布局探针只补查状态和可访问性，不替代业务验收。章节当前项以150px阅读线确定，下一标题尚未越线时保留上一节高亮，未为截图改变交互规则。

主代理检查实际 PDF 时发现比较页虽有21个 DOM 单元格，纸面却只有行标题并伴随空白页；原因是手机媒体样式同时匹配 A4，首列宽度挤出正文。修复将三组窄屏查询限定为screen，并单独固定印刷首列宽度、正文间距及尾页相邻分页；没有为打印修改屏幕结构或丢弃内容。`tests/e2e/p6-print.mjs --mock` 先稳定复现19页/正文缺失，再验证两浏览器4页单专业/6页比较；不注册账号。

最终 `--actual` 只创建1个隔离合成Student，通过真实三专业TEST_FIXTURE流程产生报告，再复用于两浏览器。两端均单专业3页（15声明）、比较6页（40声明/21格）；PDF提取核对每条正文/依据、7维/3专业与版本，非只检查DOM。根代理逐页查看全部9页，中文、跨页重复表头、限定说明和尾页正常，没有空白页、截断或孤立页脚；Chrome与Edge各9张实际渲染页逐字节相同。真实日志 `/tmp/majorpilot-p6-print-actual.log`，结果 `/tmp/majorpilot-p6-print-actual/results.json`；账号及关联数据精确清理，0付费。初始四页单专业检查是修复前证据，不与最终三页混用。

DEMO/REVIEW_PREVIEW仍不产生正式报告或比较来源，真实专业内容仍REVIEW。截图中的正式报告来自隔离库合成账户和TEST_FIXTURE；人工专业审核与45–60分钟目标用户计时仍未完成。
